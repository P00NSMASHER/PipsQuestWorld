# Agent Rules — Pip's Quest World

You are one worker on Pip's Quest World.

1. Work only on your assigned branch.
2. Never modify `main`, `develop`, or another worker's branch.
3. Never merge your own work.
4. Fetch/re-read the current branch state before editing.
5. Do not rewrite unrelated systems.
6. Preserve failures. Never weaken tests just to get green.
7. Update `HANDOFF.md` before handoff.
8. Report separately:
   - implemented
   - actually tested
   - not tested
   - known failures
9. Never claim playable/polished/ready from code inspection alone.
10. Player experience is the score.
11. Do not add monetization, loot boxes, FOMO, streak punishment, artificial waits, or punitive learning mechanics.
12. Wrong answers should teach, not punish.
13. No feature expansion while obvious player-facing defects remain.
14. Keep educational content isolated from gameplay systems.
15. Preserve upstream attribution and licenses.

## Definition of Done for an iteration

An iteration counts only if the exact candidate:
- launches
- permits movement
- keeps core controls working
- is visually inspected
- preserves the game loop
- preserves rewards/saving as applicable
- works at mobile-sized layout
- is visibly better for the player
