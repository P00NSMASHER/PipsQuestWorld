# School-Life Game

This repository has pivoted away from the Maze World direction.

Active development now targets an original Roblox school-life experience: campus exploration, timed classes, passing periods, interactive school activities, rewards, social systems, avatar customization, vehicles, homes, and after-school play.

The previous Pip's Quest / Maze World implementation is preserved in Git history and older branches for reference only; it is no longer the active product direction.

## Current school-life foundation

The new standalone Rojo project lives in `school_game/`.

See `SCHOOL_LIFE_PIVOT.md` for the product direction, implemented foundation, and next build order.
