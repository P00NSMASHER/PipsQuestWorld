# Completed-class rejoin QA contract

Base: canonical `99e12750b8b87812f3363e3691c12fb8797669bd`.

A class that is durably completed for the current Foundation `classKey` must remain non-enterable after Class/Education ephemeral state is reconstructed. Rejoin must preserve free-roam state and must not create a second progression completion.
