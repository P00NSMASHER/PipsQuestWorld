# Pip High — active Roblox project

Serve this directory with Rojo:

```bash
rojo serve school/default.project.json
```

Current vertical slice:

- generated original school blockout
- bell schedule
- class travel
- server-only question bank
- retry-friendly answer flow
- points
- mobile HUD

The campus is intentionally a blockout. It is a gameplay proving ground, not final art.
